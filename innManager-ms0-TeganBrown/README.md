# InnManager

Welcome to **InnManager**, the semester project for CIS 400.

InnManager is a hotel management application that will be developed incrementally throughout the semester. Each milestone will build upon the work completed in previous milestones.

This repository contains the starter files for **Milestone 0**.

## Getting Started

After accepting the GitHub Classroom assignment:

1. Clone **your assigned repository** to your computer.
2. Open the InnManager solution in Visual Studio.
3. Complete the requirements described in the Milestone 0 assignment.
4. Commit your work regularly as you make progress.
5. Push your commits to GitHub.
6. Follow the milestone submission instructions to create the required GitHub release.

## Important

* Work only in the GitHub repository assigned to you.
* Do not rename the solution or project unless instructed to do so.
* Do not delete or modify starter files unless the milestone instructions require it.
* Commit and push your work regularly.
* Each milestone builds upon your previous work, so maintain your repository throughout the semester.

## Semester Project Workflow

The same InnManager repository will be used throughout the semester.

Your work will progress approximately as follows:

`Milestone 0 → Milestone 1 → Milestone 2 → Milestone 3 → ...`

Do not create a new InnManager repository for each milestone.

## Submitting a Milestone

When instructed to submit a milestone:

1. Make sure your work is complete.
2. Commit all changes.
3. Push your latest commits to GitHub.
4. Create the required GitHub release using the milestone's specified tag and release name.
5. Submit the requested release information through the course LMS.

Always verify that the release contains the version of the project you intend to submit.

## Academic Integrity

Your submitted work must follow the academic integrity and collaboration policies described in the course syllabus and individual milestone instructions.
